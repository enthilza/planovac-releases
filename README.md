# Inteligentný plánovač

Nadiktuj po slovensky, čo a kedy chceš naplánovať – aplikácia z toho pripraví udalosť a zapíše ju do kalendára v telefóne (Google, Outlook…).

## Stiahnuť

[Stiahnuť planovac.apk](https://github.com/enthilza/planovac-releases/releases/latest/download/planovac.apk) · [Všetky vydania](https://github.com/enthilza/planovac-releases/releases)

Android 8.0 alebo novší, 64-bit ARM.

## Inštalácia

1. Otvor odkaz vyššie na telefóne a stiahni APK.
2. Pri prvej inštalácii povoľ „Inštalovať neznáme aplikácie“ pre prehliadač alebo správcu súborov.
3. Ďalšie verzie si aplikácia nájde sama: kontroluje ich raz denne pri štarte a na požiadanie v Nastaveniach → Skontrolovať aktualizácie.

Tento repozitár obsahuje iba zostavené APK, nie zdrojový kód.
